The swarm-routing org's [vcpkg git registry](https://learn.microsoft.com/vcpkg/maintainers/registries)
for the simulator-free C++ cores it releases: `swarm-core` first, then each
protocol's `core/`. **Being set up** (epic swarm-routing/.github#436): the
first port, its CI and the consumer instructions land with #1.
